Aeron 从入门到高级：完整学习教程

本书是给已经写过 Java（有 Netty/Kafka 使用经验）的工程师准备的 Aeron 系统性学习手册。 一共 25 章，8 大部分，从"最小 Hello World"讲到"生产级低延迟行情总线"。

配套代码在 /Users/zxj/work/workspace/quant/aeron_study/aeron 的 demo01 ~ demo10； 本书正文里出现的可运行片段大多可以直接放进对应 demo 包里跑起来。

阅读建议

  • 零基础读者：先读 ../01.aeron 零基础入门.MD，再顺序读本书 Part I~II，配合 demo01~demo05
  • 有 Kafka 背景：留意 Ch01 中的语义对比表；不要把 Aeron 当 "更快的 Kafka" 使用
  • 准备接入行情/交易系统：Part III + Part VIII 是重点
  • 需要复制状态机：Part VII
